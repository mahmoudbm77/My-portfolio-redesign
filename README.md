# My Portfolio (Redesign)

## Description
This is a redesign of my personal portfolio website, rebuilt with a new terminal-inspired, dark-themed look while keeping all the original content — my projects, skills, and experience as a software engineering student. Built as a fully front-end, responsive site, it highlights my technical work, background, and ways to get in touch. The project demonstrates practical front-end development skills, including semantic HTML structure, custom CSS styling, and vanilla JavaScript interactivity.

## What Changed in This Redesign

* New terminal/dev-console visual theme (dark background, monospace accents, terminal-style hero section)
* CSS fully separated into its own `styles.css` file for better organization and maintainability
* Reworked section layout for About, Skills, Projects, and Experience/Education
* Same content and links carried over from the original site, just presented in a new design

## Features

* Fully responsive design across desktop, tablet, and mobile
* Sections for About, Skills, Projects, Experience/Education, and Contact
* Clean, modern UI with smooth navigation
* Optimized static site with no backend dependencies

## How to Use

1. Open the live demo below
2. Browse through the About, Skills, and Projects sections
3. Use the Contact section to get in touch
4. Fully static — no setup or server required
